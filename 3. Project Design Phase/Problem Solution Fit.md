# Problem–solution fit

Published development tables are hard to compare and explain during a short academic review. The application makes their health, knowledge and income dimensions interactive, demonstrates an actual regression pipeline, and exposes its limits.

The fit is educational analytics: real data exploration, verified inference, transparent comparison and explainable scenarios. Predicting a formula-defined index is useful for teaching ML workflows but is not superior to calculating the official formula. The application cannot infer the causal effect of health/education spending, predict next year's rank, measure inequality within countries or support high-stakes allocation decisions.

Scope was narrowed from the historical account/database/policy platform to the features that can be demonstrated and verified reliably. The source data and model evidence are linked from the UI and repository.
